# 세그먼트 · 제외 규칙 v1 ( 스냅샷 1차 )

상태 : 사용자 승인 2026-10-03. 실행 순서 2 성문화. 구현 : segmentation/segment.py ( RULES_VERSION = "segment_rules_v1" ).
근거 : 13단계 구조 통계 ( sha256 66133bb5… ), 14단계 탐색 표본 1건 원문 ( 실험 영구 제외 문서 ), 15단계 반복 줄 · CSV 열 이름 ( sha256 4f7a742d… ). 세 결과 파일은 코퍼스 내용 일부를 담고 있어 공개 저장소에 두지 않는다.
적용 대상 : 코퍼스 저장소 ( 로컬 전용 ) 커밋 4268932 의 zip 3개 안 .md 파일. 코퍼스 가리킴 : corpus/v2/snapshot1_pointer.json.

## 0. 원칙

- 에이전트와 무관한 문자열 규칙만 쓴다. 본문의 의미를 보고 자르거나 빼지 않는다.
- 모든 제외는 이유 코드와 함께 기록하고 이유별 건수를 보고한다. 조용히 건너뛰지 않는다.
- 설정 파일 누락, zip 해시 불일치, doc_id 중복, 개인 페이지 주인 목록 비어 있음은 ValueError 로 멈춘다.

## 1. 문서 단위 제외

| 코드 | 조건 |
| --- | --- |
| E1_탐색표본 | doc_id 가 selection/lecture_subjects.json 의 excluded_pages.ids 에 있음 |
| E2_TODOs | 출처 team_1jo, zip 안 경로가 "1조/TODOs" 로 시작 |
| E3_소공범위밖 | 출처 team_soft_eng, 경로가 "소프트웨어 공학/과제/" 로 시작하지 않고 "소프트웨어 공학/00_공용_기준문서.md" 도 아님 |
| E4_빈문서 | 2 장 전처리 뒤 세그먼트가 하나도 남지 않음 |

- .md 가 아닌 파일 ( csv, 이미지, pdf, pptx, 중첩 zip 등 ) 은 문서로 보지 않는다. 이미지 내용 처리는 미결정이다.
- 파일명에 id 가 없는 첨부 md 도 문서로 포함한다.

## 2. 전처리 ( 순서대로 )

- P1 제목 : 첫 줄이 "# " 로 시작하면 문서 메타데이터 title 로 옮기고 세그먼트 텍스트에 넣지 않는다.
- P2 속성 : 문서의 부모 폴더 경로가 어떤 DB CSV 경로 ( 파일명 끝 " <32자리 id>_all.csv" 를 뗀 것 ) 와 같으면, 그 _all.csv 의 첫 열을 뺀 열 이름 집합 K 를 쓴다. 제목 뒤 ( 빈 줄은 건너뜀 ) 에서 연속으로 "k: " ( k ∈ K ) 로 시작하는 줄을 메타데이터 properties 로 옮긴다. DB 행이 아닌 문서에는 적용하지 않는다.
- P3 장식 ( 15단계 Lecture Note 46건 문서 빈도 근거 ) :
  - 이미지 줄 중 alt 가 "하얀리본라인3.png" 인 줄 ( 45 / 46 )
  - 첫 경계보다 앞에 있는 "- Index" 줄 ( 46 / 46 )
  - 꼬리말 : 줄 "---" 다음 첫 비공백 줄이 "- 자주 사용하는 특수 문자" 이면, "---" 부터 그 뒤의 들여쓴 줄 · 빈 줄까지 지운다 ( 46 / 46 ). 들여쓰지 않은 비공백 줄을 만나면 거기서 멈추고 footer_trailing_content 로 센다.
  - 모든 출처에 같은 규칙을 적용하고 출처별 적용 건수를 보고한다.

## 3. 경계

- B1 코드 블록 ( ``` 로 열고 닫음 ) 밖에서 0열에서 시작하는 "# ", "## ", "### " 줄이 경계다. 헤딩 줄은 새 세그먼트의 첫 줄이 된다.
- B2 첫 경계 앞에 남은 내용은 세그먼트 1개다.
- B3 "####" 이하, 들여쓴 헤딩, 코드 블록 안의 "#" 은 경계가 아니다.
- B4 헤딩 줄만 있고 내용이 없는 세그먼트는 다음 세그먼트 앞에 붙인다. 마지막이면 직전 세그먼트 끝에 붙인다.
- B5 헤딩이 없는 문서는 세그먼트 1개다 ( 13단계 : 해당 문서 최대 5,160 bytes ).
- B6 세그먼트 앞뒤 빈 줄은 지운다. 줄 내용은 원문 그대로 둔다 ( 이미지 줄 포함 ).

## 4. id 와 기록

- doc_id : 파일명 끝의 32자리 16진수 id. 없으면 "att-" + sha256( zip 안 경로 ) 앞 16자.
- segment_id : "{doc_id}#s{n}", n 은 1 부터 문서 안 순서.
- 출처 층 ( 고정 결정, Notion 위치 그대로 ) : lecture_note → 전사, team_soft_eng → 팀 ( 소공 ), team_1jo 중 개인 페이지 주인 경로 아래 → 개인 ( 주인 ), 나머지 1조 → 팀 ( 1조 ). 주인 목록은 코퍼스 저장소 selection/source_layers.json 에만 둔다.
- 산출 파일 ( 코퍼스 저장소에 둔다 ) : segments.jsonl, docs.jsonl, excluded.jsonl, report.json.

## 5. 이 규칙에서 정하지 않는 것

- 이미지 내용 처리 ( 버림 / 대체 텍스트 / OCR )
- 라벨러 뷰에 title 을 넣을지
- 한 세그먼트가 여러 노트 · 층에 나뉠 때의 채점 규칙
- 제목이 같은 페이지의 중복 처리 ( report.json 의 duplicate_titles 로 보고만 )
