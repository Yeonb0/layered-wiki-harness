# 합성 시연 코퍼스 ( 스냅샷 900 )

이 폴더의 문서는 전부 합성이다. 가상 게임 스튜디오의 위키를 흉내 낸 것이며, 실제 조직 · 실제 팀원 · 실제 페이지 내용은 하나도 없다. 이름 ( 팀원A ~ 팀원F, 팀1 · 팀2 ) 도 합성이다.

시연 경로 전용이다 ( 프로젝트 지침 v3 3절 18 ~ 22번 ). 실험 코퍼스 ( 스냅샷 1차 ), 봉인 정답셋, 파일럿 / 본실험 표본과 섞지 않고, 여기서 나온 결과는 측정 결과로 인용하지 않는다. 러너 로그의 스냅샷 차수는 900 으로 적는다.

## 구성

| 출처 id | 층 | 그룹 | 워크스페이스 | 문서 |
| --- | --- | --- | --- | --- |
| demo_studio | 전사 | 없음 | 스튜디오 위키 | 4 |
| demo_team1 | 팀 | 팀1 ( 전투팀 ) | 전투팀 | 팀 문서 4 + 개인 페이지 4 ( 팀원A · B · E · F ) |
| demo_team2 | 팀 | 팀2 ( 경제팀 ) | 경제팀 | 팀 문서 4 + 개인 페이지 4 ( 팀원C · D · E · F ) |

소속 ( selection/source_layers.json ) : 팀1만 팀원A · 팀원B, 팀2만 팀원C · 팀원D, 둘 다 팀원E · 팀원F. 개인 페이지는 워크스페이스 아래 주인 이름 폴더에 있고, 팀 맥락은 그 페이지가 놓인 워크스페이스의 팀이다.

pages/<출처 id>/ 아래가 zip 안 경로 그대로다. 문서 id 는 파일명 끝 32자리 ( 9000… ) 이다.

## 설계 의도 ( 시연 설명에 밝힌다 )

링크와 누출 경로가 보이도록 일부러 겹치는 내용을 넣었다. 링크 자체는 에이전트가 만든 것만 쓰고, 사람이 잇지 않는다.

| 의도 | 넣은 곳 |
| --- | --- |
| 상향 링크 후보 | 팀 문서가 전사 문서 ( 밸런스 수치 관리 원칙, 결정론적 게임 로직 가이드 ) 의 규칙을 따른다고 적음 |
| 하향 조건부 링크 후보 | 전투팀 회의록 10-07 ↔ 팀원A 히트스톱 실험 메모, 경제팀 회의록 10-15 ↔ 팀원C 환율 시뮬레이션 메모, 플레이테스트 운영 절차 ↔ 팀원D 설문 정리 |
| 개인 출처 → 전사 배치 후보 | 팀원B 치명타 공식 아이디어의 "고정 소수점 곱셈 정리" 절 ( 일반 지식 ) |
| 팀 간 누출 경로 | 두 팀 소속 팀원E · F 의 개인 페이지가 다른 팀 내부 용어를 담음 ( 아래 표 ) |

## 빌드
