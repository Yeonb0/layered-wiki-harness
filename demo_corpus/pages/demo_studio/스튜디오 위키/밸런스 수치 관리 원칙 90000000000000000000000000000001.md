# 밸런스 수치 관리 원칙

## 목적
게임 안의 모든 밸런스 수치 (데미지, 가격, 확률, 쿨다운)는 코드가 아니라 데이터 테이블에 둔다. 기획자가 빌드 없이 값을 바꾸고, 바꾼 이력을 남기기 위해서다.

## 변경 절차
1. 수치 변경은 테이블 파일의 풀 리퀘스트로만 한다.
2. 리뷰어 한 명 이상이 변경 전후 값을 확인한다.
3. 변경 이유를 커밋 메시지에 한 줄로 적는다.

## 검증
값을 10% 이상 바꾸는 변경은 자동 시뮬레이션을 1,000회 돌려 분포를 확인한 뒤 반영한다. 시뮬레이션은 결정론적 게임 로직 가이드의 시드 규칙을 따른다.

## 금지
코드 안에 숫자 상수로 밸런스 값을 박아 두지 않는다. 임시 값이라도 테이블에 넣고 "임시" 태그를 단다.
